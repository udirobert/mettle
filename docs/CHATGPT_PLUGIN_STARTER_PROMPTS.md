# Starter prompts (ChatGPT directory listing)

Use as **Example Prompts** on the plugin listing. User language; no pricing/trials/promos.

1. Help me prepare for this meeting — I’ll paste the email thread.
2. What are they going to ask me? Here’s the Slack thread.
3. Turn this correspondence into a meeting brief and list likely objections.
4. Brief me before my call with [Name] using this pasted thread.
5. From this email chain, what pushback should I expect?
